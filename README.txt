Maintenance Log PWA

Cómo probarla:
1. Descomprime el ZIP.
2. Sube la carpeta a un hosting web o GitHub Pages.
3. Abre la liga desde Chrome en Android.
4. Toca el menú de Chrome > Agregar a pantalla principal / Instalar app.

Nota:
Para que se instale como PWA en Android, normalmente debe abrirse desde HTTPS.
Si solo abres el archivo index.html directo, puede funcionar como página, pero no siempre como app instalable.
